# Next.js WordPress Blog - Project Overview

## Purpose
This is a comprehensive Next.js WordPress blog system designed as a commercial product targeting Japanese market blogs and corporate sites. It combines WordPress CMS functionality with Next.js performance.

## Tech Stack
- **Frontend:** Next.js 15 with TypeScript and App Router
- **Styling:** Tailwind CSS with PostCSS
- **Testing:** Vitest with React Testing Library and jsdom
- **Deployment:** Cloudflare Workers via OpenNext
- **WordPress:** WordPress REST API client integration
- **Animations:** Framer Motion
- **State Management:** React 19.1.0 with modern patterns

## Key Features
- WordPress REST API integration for content management
- Multi-environment deployment (production, staging, development, preview)
- Comprehensive testing setup with TDD methodology
- Performance optimization with Core Web Vitals monitoring
- TypeScript strict mode with advanced type safety
- Responsive design with Tailwind CSS
- SEO optimization and accessibility features
